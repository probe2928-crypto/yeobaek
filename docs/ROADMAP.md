# 여백의 지도 ROADMAP

매일 고도화 작업이 이 파일을 읽고 위에서부터 처리한다. 끝난 항목은 '완료'로 옮기고 날짜를 적는다.

## 다음 작업 (우선순위 순, 10개 이하)
1. 저널(칼럼) 연재: 사이트 문구는 '매주 월·수·금 오전 9시' — 월·수·금 고도화 회차마다 journal.json에 1편 추가하고 photo-data.js에 사진 묶음 연결
2. RUN THE MAP 필름 버튼 날짜가 미래(10.28, 10.31)로 보임 → 공개일 전 필름 표시 방식 결정(공개일 표기 or 숨김)
3. 여행 상세 모달에 일정 예시(1일차~)와 '이런 분께 맞아요' 3줄 추가 — 신청 전환율
4. 히어로 슬라이드 모션 다듬기(사진 켄번스, 자막 순차 등장) — prefers-reduced-motion 존중
5. 문의 완료 후 '카톡 공지방 들어오기' 안내 화면 — 리드를 커뮤니티로 연결
6. 검색 노출: 페이지별 description·구조화 데이터(TouristTrip) 추가
7. run.html 모바일 메뉴도 메인과 같은 메뉴 버튼 방식으로 통일
