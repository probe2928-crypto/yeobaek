# 여백의 지도 ROADMAP

매일 고도화 작업이 이 파일을 읽고 위에서부터 처리한다. 끝난 항목은 '완료'로 옮기고 날짜를 적는다.

## 다음 작업 (우선순위 순, 10개 이하)
1. 저널(칼럼) 연재: 사이트 문구는 '매주 월·수·금 오전 9시' — 월·수·금 고도화 회차마다 journal.json에 1편 추가하고 photo-data.js에 사진 묶음 연결
2. 시라카와고 사진이 1장뿐 → Unsplash/Commons에서 갓쇼 집 내부·다락 사진 추가(칼럼 본문 사진용)
3. 메인 RUN THE MAP 카드의 '예상 ○○만 원' 표기가 브랜드 가격 규칙('+α')과 맞는지 세준 확인 후 정리
4. 필름 사진 점검 자동화: 작업 환경에서 Commons API·raw.githubusercontent·github.io 직접 조회가 막혀 있음(10-27~10-29 동일, WebFetch도 github.io·Commons 둘 다 막힘 → 라이브 확인·필름 사진 점검을 3일째 못 함) → GitHub Actions로 매일 Commons 확인하는 워크플로 검토
5. 저널 칼럼에 카테고리 필터(HISTORY / FOOD / ART) + '다음 칼럼' 이어 읽기 링크
6. 여행 상세 모달 공유 링크(#trip-3 같은 해시로 바로 열기) + 모달별 og 미리보기
7. run.html에도 구조화 데이터(대회 Event 목록) — races.json이 외부 저장소라 빌드 없이 넣는 방법 검토

## 사용자 조치 필요
- 관광사업(국내외여행업) 등록번호·사업자 정보 → 푸터 'Concept Preview · 정식 예약·결제 서비스 미운영' 문구 교체
- RUN THE MAP 카드 '예상 ○○만 원' 표기를 '+α' 규칙에 맞춰 바꿀지 결정
- 여백의 지도 전용 인스타 계정이 생기면 알려주기 (지금은 @lifejunjun 링크)
