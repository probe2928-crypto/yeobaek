# 여백의 지도 ROADMAP

매일 고도화 작업이 이 파일을 읽고 위에서부터 처리한다. 끝난 항목은 '완료'로 옮기고 날짜를 적는다.

## 다음 작업 (우선순위 순, 10개 이하)
1. 저널(칼럼) 연재: 사이트 문구는 '매주 월·수·금 오전 9시' — 월·수·금 고도화 회차마다 journal.json에 1편 추가하고 photo-data.js에 사진 묶음 연결
2. 여행 상세 모달에 일정 예시(1일차~)와 '이런 분께 맞아요' 3줄 추가 — 신청 전환율
3. 문의 완료 후 '카톡 공지방 들어오기' 안내 화면 — 리드를 커뮤니티로 연결
4. run.html 모바일 메뉴도 메인과 같은 메뉴 버튼 방식으로 통일
5. 검색 노출: 페이지별 description·구조화 데이터(TouristTrip) 추가
6. 시라카와고 사진이 1장뿐 → Unsplash/Commons에서 갓쇼 집 내부·다락 사진 추가(칼럼 본문 사진용)
7. 메인 RUN THE MAP 카드의 '예상 ○○만 원' 표기가 브랜드 가격 규칙('+α')과 맞는지 세준 확인 후 정리
8. 필름 사진 점검 자동화: 작업 환경에서 Commons API가 막혀 있음 → 브라우저/다른 경로로 확인하는 방법 마련
